# Dental Snore Clinic - د. مهند الكسواني

موقع Dental Snore Clinic المتخصصة في المركز الأوروبي - عمان، الأردن

## نظرة عامة

موقع طبي متخصص لعيادة د. مهند الكسواني لعلاج الشخير واضطرابات النوم، يقدم خدمات شاملة للبالغين والأطفال.

## الميزات

- ✅ تصميم متجاوب يدعم اللغة العربية (RTL)
- ✅ واجهة حديثة وجذابة باستخدام Tailwind CSS
- ✅ مكونات UI متقدمة من shadcn/ui
- ✅ تحسين محركات البحث (SEO) 
- ✅ أقسام متخصصة للبالغين والأطفال
- ✅ نموذج حجز المواعيد
- ✅ آراء المرضى
- ✅ معلومات تفصيلية عن الطبيب والخدمات

## التقنيات المستخدمة

- **Next.js 15** - إطار عمل React
- **TypeScript** - لغة البرمجة
- **Tailwind CSS** - تنسيق الصفحات
- **shadcn/ui** - مكونات واجهة المستخدم
- **Lucide React** - الأيقونات

## التشغيل المحلي

```bash
# تثبيت الحزم
npm install
# أو
pnpm install

# تشغيل الخادم المحلي
npm run dev
# أو
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح لرؤية النتيجة.

## البناء للإنتاج

```bash
npm run build
npm start
```

## الخدمات المقدمة
